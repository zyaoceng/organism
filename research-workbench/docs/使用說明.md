# 研究工作台（Research Workbench）使用說明

## 要搞懂什麼

這個網站把一次研究記成一條鏈：證據 → 假設 → 財務數字 → EPS → 目標價，之後再接交易和檢討。
每次改變看法都存成一筆「研究更新」，幾個月後可以查回當時相信什麼、為什麼、哪份資料讓你改變想法。

## 怎麼把網站跑起來？

**這三行指令要在一台電腦上執行，GitHub 網頁本身不能執行指令；最省事的做法是用 GitHub Codespaces，它在瀏覽器裡開一台雲端電腦給你用。**

### 用 GitHub Codespaces（不用在自己電腦裝任何東西）

1. 打開 https://github.com/zyaoceng/organism 。
2. 網頁左上角有一個寫著 `main` 的分支按鈕，點開後選 `claude/vibrant-thompson-s3npyj`。程式目前只在這個分支上，合併進 `main` 之後就不用切換。
3. 點綠色的「Code」按鈕，切到「Codespaces」分頁，按「Create codespace on claude/vibrant-thompson-s3npyj」。
4. 等一到兩分鐘，瀏覽器會出現一個類似 VS Code 的編輯器畫面。
5. 畫面下方有一個「Terminal（終端機）」視窗。沒看到的話，按左上角選單 ☰ → Terminal → New Terminal。
6. 在終端機裡一行一行貼上指令，每貼一行按 Enter，等它跑完再貼下一行：

```bash
cd research-workbench
npm install
npm run dev
```

7. `npm install` 會跑一到兩分鐘，最後出現「added … packages」就是完成。
8. `npm run dev` 跑起來後，終端機會出現 `Local: http://localhost:5173/`，右下角同時會跳出「Open in Browser」的提示，點它就會打開網站。
9. 沒看到提示時，點終端機旁邊的「Ports（連接埠）」分頁，找到 5173 那一列，點地球圖示打開。
10. 想先看一家填好數字的範例公司，在第 6 步的 `npm run dev` 之前多跑一行 `npm run seed:demo`。

使用 Codespaces 要注意三件事：
- 資料存在這台雲端電腦的 `research-workbench/data/` 資料夾。Codespace 停用一段時間後會被 GitHub 刪除，資料也會跟著消失。重要資料請定期用 總覽頁的「匯出 JSON」下載備份。
- 下次再用時，到 github.com/codespaces 打開同一個 codespace，在終端機執行 `cd research-workbench` 和 `npm run dev` 兩行即可，不用再跑 `npm install`。
- GitHub 個人帳號每月有免費的 Codespaces 使用時數，超過會收費，用完請在 github.com/codespaces 把它停止（Stop codespace）。

### 在自己的電腦上執行

1. 到 https://nodejs.org 下載並安裝 LTS 版的 Node.js（需要 20.10 以上）。
2. 用 Git 或 GitHub Desktop 把 repo 下載到電腦，並切到 `claude/vibrant-thompson-s3npyj` 分支。
3. 打開終端機（Windows 用「命令提示字元」或 PowerShell，Mac 用「終端機」），進到 `organism` 資料夾，執行上面同樣的三行指令。
4. 用瀏覽器打開 http://localhost:5173 。
5. 資料存在 `research-workbench/data/`，備份就是複製這個資料夾。
6. 網站沒有登入功能，只在你自己的電腦上開放，不要架到公開網路上。

## 怎麼切換中文和英文？

**按左下角的「中文／English」按鈕就能切換，網站會記住你的選擇。**

- 公司列表頁的標題旁邊也有同一組按鈕。
- 第一次打開時，網站跟著瀏覽器的語言決定用中文或英文。
- 切換只改介面文字，你自己寫的節點名稱、筆記、證據都維持原樣。
- 在中文介面新增公司時，標準範本的節點名稱會是中文，例如營收、毛利率、目標本益比；在英文介面新增則是英文。
- 公式裡存的是節點編號，所以節點名稱用中文或英文，計算結果都一樣。

## 第一次研究一家公司要怎麼做？

**照「建立公司 → 填歷史數字 → 填預估 → 附上證據 → 提交」五步走。**

1. 首頁按「+ 新增公司」，在最上面的搜尋框輸入代號或公司名稱（例如 `7899` 或「景美」），點搜尋結果，公司名、代號、交易所、資料來源代號和股價來源會自動填好。
2. 網站用標準研究模板建立一棵樹：EPS 底下有營收、毛利率、費用、業外、稅、淨利、稀釋股數；P/E 底下有 EPS 成長、ROIC、再投資報酬率；最下面是目標價。中文介面下，三個業務節點叫「業務 A」「業務 B」「業務 C」。期間預設 2024A、2025A、2026E、2027E、2028E，金額單位是新台幣億元。
3. 把業務 A、B、C 改成你自己的業務切法。點一列，按 `F2` 改名，按 `A` 新增子項目。管理層的部門分法不好用時，照你自己的分法切。
4. 在實際年度（A）的格子填財報數字，在預估年度（E）填成長率、毛利率等假設。點格子直接打數字，按 Enter 換下一列。百分比格打 `40` 就是 40%。
5. 選一個重要假設，在右邊面板加上證據：貼網址按 Enter、把 PDF 拖進去、`Ctrl+V` 貼截圖，或寫一則筆記。
6. 按畫面右下角的「檢查並提交」，寫標題、知情日期（你知道這些資訊的日期）、理由，按「提交研究更新」。

## 單位要怎麼設？台股和美股有什麼不同？

**建立公司時選的貨幣決定模板的預設單位：新台幣用「億元、億股」，美元用「百萬美元、百萬股」。**

| | 台股例子：光寶 2301 | 美股例子：Vertiv VRT |
|---|---|---|
| 建立公司時的交易所 | TWSE（上櫃選 TPEx） | NYSE 或 NASDAQ |
| 自動帶出的代號 | 2301.TW（上櫃為 .TWO） | VRT |
| 貨幣 | TWD | USD |
| 營收、毛利、淨利的單位 | TWD 億 | USD mn（百萬美元） |
| 稀釋股數的單位 | 億股 | 百萬股 |
| EPS 的單位 | TWD/sh（每股新台幣） | USD/sh（每股美元） |
| 營收 1,853.6 的意思 | 1,853.6 億新台幣 | 1,853.6 百萬美元，約 18.5 億美元 |

- 選 NYSE 或 NASDAQ 時，貨幣欄會自動變成 USD，模板的金額和股數會自動用百萬為單位。
- EPS 等於淨利除以稀釋股數，所以淨利和股數必須用同一個單位：新台幣的淨利用億元，股數就用億股；美元的淨利用百萬美元，股數就用百萬股。兩邊單位不一致時，EPS 這一列會出現警告，並寫出結果差了幾倍。
- 單一節點的單位可以在右邊面板上方改：第一個下拉選單選種類（金額、每股、百分比、倍數、股數、數量），第二個選貨幣（TWD、USD 等），第三個選位數（units、thousand、million、億、billion）。

### 同一家公司有美元和新台幣數字時怎麼辦？

**先用一個匯率節點把美元換成新台幣，再加總；系統不會自動換匯。**

例子：台灣公司的某項業務用美元估算市場規模。
1. 新增節點「AI 電源 TAM」，單位選「USD」＋「十億」，填 2028E 為 8.8。
2. 新增節點「USD/TWD 匯率」，單位選「純數字」，填 32。
3. 業務營收節點的單位是「TWD 億」，公式寫 `[AI 電源 TAM] * [市占率] * [USD/TWD 匯率] * 10`。
4. 最後的 `* 10` 把「十億新台幣」換成「億新台幣」：8.8 十億美元 × 32 = 281.6 十億新台幣 = 2,816 億新台幣。

- 把美元節點和新台幣節點直接相加（例如 `[台灣營收] + [美國營收]`）時，會出現「幣別不同」警告。
- 同一種貨幣但位數不同（例如億元加百萬元）時，會出現「數量級不同」警告。
- 改一個節點的位數時，勾選「變更數量級時換算數值」會一併換算數字，例如 1,853.6 億會變成 185,360 百萬。這個節點本身有公式、或有其他公式用到它時，系統會拒絕換算，因為公式不會自動換位數；這時請整條計算鏈一起改，或只改標籤不換算。

## 樹狀圖上的顏色和記號是什麼意思？

**藍字是你手打的數字，黑字是公式算出來的，黃底是還沒提交的改動。**

- 灰底欄位是實際年度，白底是預估年度。
- 格子左邊的小圓點代表這格有空頭或多頭情境的覆寫值。
- 格子右上角的橘色三角代表你在公式格手打了數字，蓋掉公式結果。這通常是錯誤來源，右邊的「模型檢查」會列出來。
- 深黃底是你直接改的格子，淺黃底是被連動改到的格子。
- 列名後面的 `ƒ` 代表有公式，`📎2` 代表連了兩份證據，`!` 代表有錯誤。
- 點一列後，這一列公式用到的列會出現藍色「來源」，用到這一列的列會出現橘色「引用」。公式跨到其他分支時，靠這個看出關聯。

## 公式要怎麼寫？

**在右邊面板的 Formula 欄用中括號寫名稱，按 `Ctrl+Enter` 套用。**

- 例子：`[TAM] * [Market Share] * [ASP]`。
- 去年乘成長率：`PREV([營收]) * (1 + [成長率])`。`PREV` 讀前一期，不算循環參照。
- 產能上限：`MIN([市場需求], [產能])`。
- 加總底下所有子業務：`SUM(CHILDREN())`。之後新增的業務會自動算進去。
- 指定某一年：`[EPS]@FY2028`。目標價公式預設是 `[EPS]@FY2028 * [Target P/E]`。
- 打中括號時會跳出名稱清單可以點選。
- 公式形成循環時會被擋下，並顯示循環路徑，例如「EPS → 淨利 → 稅 → EPS」。
- 輸入值空白時，下游格子會顯示「—」，滑鼠移上去會寫缺哪一格。系統不會把空白當成 0。

## 空頭、基準、多頭三種情境怎麼設？

**基準情境放共用數字，空頭和多頭只記跟基準不同的格子。**

- 畫面左上角切換 Bear / Base / Bull，或在樹上按數字鍵 1、2、3。
- 在空頭情境下改格子，只會記成空頭的覆寫，基準數字不變。
- 右邊面板的 Values 表同時列出三種情境，灰色斜體代表沿用基準。
- 實際年度三種情境共用，改不了覆寫。

## 收到新資訊時要怎麼更新？

**先附證據，再改所有相關假設，最後一次提交成一筆研究更新。**

- 同一份新資訊可以同時改多個假設，例如市占率、產能、毛利率。
- 改完先打開底部面板，會看到三樣東西：改了哪些格子、EPS 和目標價在三種情境下怎麼變、影響一路傳到哪些科目。
- 提交後，系統會算出每個假設單獨造成多少 EPS 和目標價變動。
- 看完新資訊決定不改任何數字時，照樣可以提交，這筆會記成「檢查點」，代表你看過並維持原判斷。
- 知情日期不能比上一筆早，也不能引用在知情日期之後才發表的資料。這是為了避免事後諸葛。
- 改錯了可以按 `Ctrl+Z` 復原；還沒提交的草稿可以整份丟棄。

## 目標本益比要怎麼決定？

**在 Valuation 頁自己輸入三種情境的本益比，系統只負責整理判斷用的資料。**

- 這一頁列出 EPS 成長、ROIC、再投資報酬率、毛利率，以及目前股價換算的本益比。
- 歷史本益比區間和同業表要自己填，每一格可以寫來源和日期。
- 每種情境的本益比旁邊要寫理由，這些理由會跟著研究更新一起存檔。
- 可以填三種情境的機率，系統會算出機率加權目標價。

## 幾個月後怎麼回頭檢討？

**打開 History 頁，所有研究更新都在時間軸上，每一筆都能完整還原。**

- 點任一筆更新，會看到當時的理由、引用的證據、改了什麼、對 EPS 和目標價的影響，以及當時的股價。
- 按「查看快照」可以用唯讀模式看當時的整棵樹、當時連結的證據、當時的論點。
- 按「還原到草稿」會把舊版本放回草稿，提交後成為新的一筆，舊紀錄不會被改寫。
- 「預估演變與校準」分頁畫出同一個數字（例如 2028 年 EPS）在每次更新時的估計值。那一年財報公布、期間改成實際（A）後，會多一條實際值的線，直接看出估計誤差。
- 右邊面板最下面的「變更紀錄」會列出這一格每次被改的日期、數字和理由。
- 「檢討」分頁可以寫檢討，勾選錯誤出在證據品質、證據解讀、假設幅度、模型公式、時機、本益比、交易執行或風險控管。分類由你判斷，系統不會自動歸因。

## 交易紀錄要怎麼用？

**在 Trades 頁記錄進場，系統自動帶入當天的 ATR、2 倍 ATR 停損和當時的目標價。**

- 目標價取自進場日當天已經提交的研究更新，進場日之後才做的研究不會被拿來用。
- 出場後填出場日期、價格和理由。
- 表格會算報酬、R 倍數、持有期間最大浮盈和最大浮虧，也會算「照 2 倍 ATR 移動停損會在哪天出場」。
- 拿這兩個數字比對，可以分開檢討「研究判斷錯」和「交易執行差」。
- Market 頁的 K 線圖會標出進出場點、停損線和三種情境的目標價線。

## 股價抓不到怎麼辦？

**到「行情」頁右邊按「🔍 用代號或名稱搜尋」，輸入代號或公司名稱，點正確的那一筆，網站會自動換成對的代號和股價來源。**

- 最常見的原因是代號後綴選錯：上市股票在 Yahoo 是 `.TW`，上櫃和興櫃股票是 `.TWO`，例如景美科技（7899）是興櫃股，要用 `7899.TWO`。
- 選 Yahoo 當來源時，網站現在會自動試 `.TW` 和 `.TWO` 兩種，選錯後綴也抓得到。
- 台股建議用 FinMind 當股價來源，它有上市、上櫃、興櫃的每日股價，不用註冊就能用，每小時有請求次數上限。
- 請求次數不夠時，到 FinMind 網站註冊拿 token，啟動前在終端機輸入 `export FINMIND_TOKEN=你的token`，再執行 `npm run dev`。
- 想要券商等級的即時報價，可以申請富果（Fugle）的 API 金鑰，啟動前輸入 `export FUGLE_API_KEY=你的金鑰`，股價來源選單就會多出「富果 Fugle」。
- 美股用 Yahoo，搜尋英文名稱或代號即可，例如 `NVIDIA` 或 `NVDA`。
- 全部來源都抓不到時，可以從別處下載日線 CSV，在同一頁匯入。

## 其他常用功能在哪裡？

**`Ctrl+K` 搜尋全部內容；Overview 頁可以匯出和存成模板。**

- 搜尋範圍包括節點名稱、筆記、證據、催化劑、論點和研究更新的理由。
- Catalysts 頁記錄法說會、客戶認證、新廠量產等事件。事件發生前先寫預期結果，事後補上實際結果；舊版本會自動保留。
- 在任何一個節點的右邊面板可以寫「論點」和「推翻條件」，例如「FY27 開始導入 800V；若 FY27 Q2 前沒有雲端大廠認證就推翻」。
- 總覽頁的「匯出 JSON」下載整家公司的完整紀錄；「另存為範本」把這家公司的樹狀結構存成模板，下一家公司可以直接套用。

| 按鍵 | 作用 |
|---|---|
| `A` | 新增子項目 |
| `S` | 新增同層項目 |
| `F2` | 改名 |

| `Ctrl+K` | 搜尋 |

## 目前有哪些限制？

**Yahoo、FinMind、富果三個股價來源都還沒在開發環境實測過，因為開發環境的網路擋掉了這些網站；在 Codespaces 或你自己的電腦上可以連線。**

- Yahoo 用的是非官方介面，隨時可能變動。
- FinMind 和富果照官方文件串接，第一次使用時請確認股價和看盤軟體一致。
- CSV 匯入支援 Yahoo 的欄位格式，也支援證交所的中文欄位（日期、開盤價、最高價、最低價、收盤價、成交股數）。
- 一個模型只能用一種期間頻率，年度或季度擇一。
- 可以匯出 JSON，還不能匯入。
- 切到中文後，少數外部來源的訊息（例如 Yahoo 回傳的錯誤原文）可能仍是英文。

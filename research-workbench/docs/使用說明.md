# 研究工作台使用說明（Mac 版）

## 這個網站是做什麼的？

**研究工作台把一次研究記成一條鏈：證據 → 假設 → 財務數字 → EPS → 目標價，之後再接交易和檢討。**

- 每次改變看法都存成一筆「研究更新」，幾個月後可以查回當時相信什麼、為什麼、哪份資料讓你改變想法。
- Mac 版裝在你自己的 Mac 上，開機登入後會自動在背景執行，不用再開終端機打指令。
- 你可以在 Claude 和 ChatGPT 的桌面版對話裡直接讀寫研究工作台，也可以把研究更新和交易同步成 Obsidian 筆記。
- 「終端機」是 Mac 內建的一個 App，用來輸入文字指令；在「應用程式 → 工具程式」裡可以找到，也可以按 `⌘ + 空白鍵` 搜尋「終端機」。

## Codespaces 裡的舊資料要怎麼救出來？

**先在舊的 Codespace 裡產生一個備份檔 `wb-data.tgz`，下載到 Mac 的「下載項目」資料夾，安裝程式會自動找到它並匯入。**

- Codespace 是 GitHub 在瀏覽器裡提供的雲端電腦，你以前就是在那裡執行研究工作台。
- GitHub 會刪除停用一段時間的 Codespace，資料也會一起消失，所以請先做這一步。

1. 打開 https://github.com/codespaces ，在清單裡找到之前用的 codespace，點它的名稱打開。
2. 為了避免它被刪除，可以在清單裡那一列的「⋯」選單選「Keep codespace」。
3. 等編輯器畫面出現後，在下方的「Terminal（終端機）」視窗貼上下面這一行指令，按 Enter：

```bash
cd /workspaces/organism/research-workbench && node -e "const D=require('better-sqlite3');const d=new D('data/workbench.db');d.backup('wb.db').then(()=>{d.close();console.log('ok')})" && tar czf wb-data.tgz wb.db $(ls -d data/attachments 2>/dev/null)
```

4. 終端機印出 `ok` 就代表備份成功；這個檔案包含你最後一次的修改和所有附件。
5. 在左側的檔案清單找到 `research-workbench` 資料夾裡的 `wb-data.tgz`，按右鍵選「Download」。
6. 把檔案存到 Mac 的「下載項目」資料夾，檔名保持 `wb-data.tgz`。

如果 Codespace 已經被刪除：
- 舊資料已經無法救回，新版會從空白開始。
- 安裝步驟完全一樣，只是不會出現匯入的問題。

## 怎麼安裝到 Mac？

**打開「終端機」，貼上下面這一行指令，按 Enter，照畫面的問題回答即可。**

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/zyaoceng/organism/claude/vibrant-thompson-s3npyj/research-workbench/scripts/mac/install.sh)"
```

- 需要 macOS 11 或更新的版本，Apple 晶片和 Intel 晶片的 Mac 都可以。
- 安裝程式會自己下載需要的 Node.js（執行研究工作台的程式），不用另外安裝。
- 它只會安裝已經通過測試的版本。
- 安裝會下載並建置程式，其中「安裝套件 npm ci」這一步約 1–3 分鐘，畫面上每一步都會印出 `==>` 開頭的說明。
- 最後出現「安裝完成 / Installed」就代表完成，下面會列出怎麼打開、資料放在哪裡、AI 和 Obsidian 的連接結果。

## 安裝時會問我哪些問題？

**最多會問四類問題：要不要匯入舊資料、要不要結束 Claude 或 ChatGPT、要連接哪一個 Obsidian 筆記庫，以及要不要覆蓋現有資料。**

- 「下載項目」裡有 `wb-data.tgz` 時，它會先列出要匯入的公司、研究更新、交易、證據和附件數量，問你「要匯入這些資料嗎？」。
- 匯入完成後，這個檔案會被改名成 `wb-data.imported-日期.tgz`，之後重跑安裝指令就不會再匯入一次。
- 如果研究工作台裡已經有公司資料，它會要求你打 `yes` 才會用匯入的資料取代；取代前會先把目前的資料庫備份到 `backups/`。
- 如果終端機沒有權限讀取「下載項目」，畫面會提示你到「系統設定 → 隱私權與安全性 → 檔案與資料夾 → 終端機」打開「下載項目」，再執行一次。
- Claude 桌面版或 ChatGPT 桌面版正在執行時，它會問你要不要先結束它；結束後重新打開即可，對話不會不見。
- 它會列出你電腦上的 Obsidian 筆記庫，請輸入編號；輸入 `0` 代表先不要連接 Obsidian。
- 舊資料檔放在別的位置時，在指令最後加上 `-- --import 檔案路徑` 指定它。

## 安裝好之後怎麼打開？

**在 Finder 打開你的個人「應用程式」資料夾，雙擊「研究工作台」；或在瀏覽器打開 http://127.0.0.1:4310/ 並加入書籤。**

- 「研究工作台」App 放在 `~/Applications/`，也就是你個人帳號底下的「應用程式」資料夾（和系統的「應用程式」資料夾是兩個不同的地方）。
- 把這個 App 拖到 Dock 或桌面，之後點一下就能打開。
- 研究工作台在背景執行，登入 Mac 後會自動啟動，不用開終端機。
- 點 App 時如果背景服務沒有在執行，它會嘗試啟動服務；啟動不了時會跳出視窗，請你到「系統設定 → 一般 → 登入項目與延伸功能」，在「允許在背景執行」打開「node」（或 ResearchWorkbench），再點一次 App。
- 第一次打開時是中文介面。

## 基本模式和進階模式差在哪裡？

**網站預設是基本模式，只留每天會用的頁面和工具；勾選左下角的「進階模式」就會顯示全部頁面和工具。**

- 兩種模式用的是同一份資料，切換不會改動任何數字。
- 首頁、交易日誌頁和設定頁的右上角也有同一個開關，網站會記住你的選擇。
- 基本模式下點到隱藏頁面的連結（例如右邊面板裡的證據標題），頁面照樣會打開，側欄會暫時在「更多」底下標出你在哪一頁。
- 只有進階模式才有的工具：中文／English 切換、側欄的 `Ctrl+K` 提示、總覽表的「加權目標價」欄、把檔案拖進右邊面板、證據的關係和頁碼、論點、節點的變更紀錄、公式說明、計算關聯（來源／引用）、期間的新增刪除和 A／E 切換、K 線圖的區間和均線設定、MFE／MAE 和移動停損、CSV 匯入、提交時的證據清單和備註、影響的因果鏈和歸因、快照比較、預估演變的折線圖、成長與報酬表、評價重估論點、另存為範本、設定頁的系統詳細資料。
- 想切換中文和英文，先打開進階模式，再按左下角的「中文／English」按鈕；切換只改介面文字，你自己寫的名稱和筆記不變。

## 側欄的每一頁是做什麼的？

**基本模式的側欄有「模型、估值、交易、歷史」四頁；進階模式多一組「更多」，裡面是「證據、催化劑、總覽」。**

- 「模型」：樹狀圖，從營收、毛利率一路算到 EPS 和目標價，你在這裡改假設。
- 「估值」：自己輸入三種情境的目標本益比，整理歷史本益比區間和同業表。
- 「交易」：上方是 K 線圖和目前股價，下方記錄這家公司的進場、出場、停損和反思。
- 「歷史」：所有研究更新的時間軸，加上「預估演變與校準」「檢討」「AI 活動」三個分頁。
- 「證據」（進階）：這家公司所有的證據清單。
- 「催化劑」（進階）：法說會、客戶認證、新廠量產等事件，事前寫預期，事後補結果。
- 「總覽」（進階）：公司描述、論點與推翻條件、最近的研究更新、研究日誌、反思、這家公司的 AI 活動，以及「匯出 JSON」和「另存為範本」。
- 側欄底部在兩種模式都有：「← 所有公司」「交易日誌」「設定」「匯出 JSON」和進階模式開關。

## 首頁的總覽表怎麼看？

**首頁把所有公司列成一張表，同時列出股價、目標價、上漲空間，以及哪家公司有事情要處理。**

- 欄位有：公司、股價、目標價（基準）、上漲空間、最近研究、草稿、持倉、催化劑、論點、AI；進階模式另外顯示「加權目標價」。
- 目標價取自每家公司最近一次提交的研究更新。
- 「加權目標價」是用估值頁填的三種情境機率加權算出的目標價。
- 股價很久沒更新時會標「過期」，超過 7 天沒有新股價會標「已 N 天沒有新股價」。
- 「草稿」欄出現「未提交」代表這家公司有改過、還沒提交的數字。
- 「持倉」欄列出持有中的筆數和平均 R 倍數（R 倍數是報酬除以進場時設定的停損距離）。
- 「催化劑」欄會標出逾期的事件，「論點」欄會標出到了檢查日的論點。
- 「AI」欄顯示 AI 最近在這家公司做過的事。
- 點欄位標題可以排序，上方的搜尋框可以依名稱或代號篩選，勾選「顯示已封存」會列出封存的公司。
- 點任何一列就會打開那家公司的模型頁。

## 「更新全部股價」做了什麼？

**按首頁的「更新全部股價」，伺服器會在背景一家一家抓最新的日線股價，畫面上會顯示進度。**

- 進行中會顯示「更新股價中 3/12…」這類進度，你可以繼續做別的事。
- 完成後會寫出成功、失敗和略過的檔數，按「查看失敗項目」可以看哪幾檔沒更新和原因。
- 股價來源達到請求上限時，畫面會寫出還有幾檔沒更新，以及大約幾秒後可以再試。
- 只想更新一家公司時，在那家公司頁面右上角的股價旁按更新按鈕。

## 交易日誌在哪裡？

**首頁右上角的「交易日誌」按鈕，或側欄底部的「交易日誌」連結，會打開所有公司的全部交易。**

- 每筆交易列出進出場、報酬、損益、R 倍數、持有天數、進場時的研究、檢討和 Obsidian 反思的摘錄。
- 損益保留各自的幣別，不換算也不跨幣別加總，所以台股和美股的損益會分開列。
- 上方有摘要：已出場筆數、勝率、平均 R，以及檢討裡出現的錯誤類型。
- 可以用「持有中／已出場」、公司、進場日期區間篩選，也可以勾「只看未檢討」或「已出場、尚無反思」。
- 還沒檢討的交易旁邊有「寫檢討」連結，點了會跳到那家公司的檢討分頁。
- 進階模式另外顯示 MFE／MAE（持有期間最大浮盈和最大浮虧）和移動停損的出場點。

## Ctrl+K 能做什麼？

**在首頁和交易日誌頁按 `Ctrl+K` 可以輸入名稱或代號切換公司；在公司頁面裡按 `Ctrl+K` 可以搜尋公司和這家公司的所有內容。**

- Mac 上按 `⌘ + K` 也有同樣的作用。
- 公司頁面裡的搜尋範圍包括公司、節點名稱、筆記、證據、催化劑、論點和研究更新的理由。
- 兩種模式都能用這個快捷鍵。

## 怎麼在 Claude 裡使用？

**安裝程式已經把研究工作台登記到 Claude 桌面版和 Claude Code；打開 Claude 桌面版的 Chat 分頁，直接用中文請它做事即可。**

- 這個連接用的是 MCP（Model Context Protocol，讓 AI App 呼叫你電腦上其他程式的標準方式）。
- 研究工作台提供一組工具給 AI，例如「列出公司」「讀取模型」「修改草稿」「提交研究更新」「記錄交易」。
- Claude 桌面版請用 Chat 分頁；Cowork 看不到這個連接。
- 安裝時如果 Claude 桌面版正在執行並被結束了，請重新打開它。
- Claude Code 是在終端機裡使用的 Claude；安裝程式把研究工作台登記在你帳號的全域設定裡，在任何資料夾執行 `claude` 都能用。
- 研究工作台的網站要在執行中，AI 才連得到；開機登入後它會自動執行。
- 想讓 Claude 每次都遵守相同的規則，到網站的「設定」頁按「複製」，把「貼給 AI 的指示」貼到 Claude 的「專案 → 專案指示」。

## 怎麼在 ChatGPT 桌面版裡使用？

**ChatGPT 桌面版只在 Work 模式、而且不在 ChatGPT 專案裡的對話才連得到研究工作台。**

- 安裝程式會把研究工作台寫進 ChatGPT 桌面版使用的設定檔 `~/.codex/config.toml`，寫入前會先備份。
- 在 ChatGPT 專案裡面開的對話用不到這個連接，請在專案外開新對話。
- 想讓 ChatGPT 每次都遵守相同的規則，把網站「設定」頁複製的指示貼到 ChatGPT 的「設定 → 個人化 → 自訂指令」。

## 可以對 AI 說哪些話？

**用平常的中文描述你要做的事，提到「研究工作台」和公司名稱或代號，AI 會自己挑工具。**

- 「用研究工作台列出所有公司，依上漲空間排序。」
- 「看一下光寶 2301 在研究工作台的模型，2027 年的 EPS 是怎麼算出來的？」
- 「把光寶 2027E 的毛利率改成 24%，先給我看預覽。」
- 「剛剛的修改提交成研究更新，標題寫『Q3 法說：上調毛利率』，理由是管理層上調了產品組合的指引。」
- 「記一筆交易：2330 今天用 1,050 元買進 2 張，停損 1,000 元。」
- 「我昨天把 2330 的部位用 1,120 元全部賣掉了，幫我記出場。」
- 「更新全部股價，完成後告訴我哪些失敗。」
- 「列出我所有還沒檢討的交易。」
- 「把今天討論的結論、決定和待辦存進研究工作台。」

## AI 做哪些事之前會先問我？

**改模型、提交研究更新、新建公司、價格看起來不對的交易，都要先讓你看過或得到你同意；其中幾項由伺服器強制檢查，AI 跳不過去。**

- 改草稿：AI 要先做一次預覽，列出每一格改動前後的數值、EPS 和目標價的變化，給你看過後才寫入。
- 提交研究更新：AI 要先「預覽提交」，列出所有改動、EPS 與目標價前後和要記錄的股價；預覽 15 分鐘內有效，過期或草稿又被改過就要重新預覽。
- 大幅變動：任何情境的 EPS 或目標價變動超過 30%、第一次建立或被清空，或任何一格數值相差 20 倍以上，伺服器會擋下提交，直到 AI 在對話裡問過你、你明確同意。
- 你自己的修改：草稿裡有你在網站上改了還沒提交的數字時，AI 不能提交，請你先在網站提交或捨棄。
- 新建公司：AI 記交易時找不到這家公司，要先問你要不要新建。
- 交易價格：進場價或出場價超出當天 K 棒的最高最低價時會被拒絕，AI 要和你確認價格沒錯才能再送一次。
- 知情日期和交易日期不能晚於今天；證據一定要有發布日期，AI 給的日期在網站上會標「AI 給的日期」。
- ChatGPT 桌面版另外設定成每次執行「提交研究更新」「記錄交易」「記錄出場」前都跳出確認；其他工具直接執行。
- 數字一定要帶單位（例如 `18.5%`、`1,234 億`、`25x`），伺服器會換算成節點的單位，避免把百分比或金額單位弄錯。

## AI 提交的研究更新可以撤回嗎？

**不行；研究更新一旦提交就永久保存、不能修改或刪除（AI 提交的也一樣），發現錯誤時只能在「歷史」頁按「標記錯誤，校準時排除」。**

1. 打開那家公司的「歷史」頁，在時間軸點選那一筆研究更新。
2. 按「標記錯誤，校準時排除」，寫下錯在哪裡，按確定。
3. 這一筆會加上刪除線，不再列入預估演變的圖表、變動和校準表，你寫的原因會和標記一起保存。
4. 改變主意時，按「取消標記」就會恢復。

其他相關的事：
- 第一筆研究更新（建立公司時的初始版本）沒有這個按鈕，不能標記。
- 每一筆研究更新都會寫明「提交者」，看得出是你還是哪一個 AI。
- 想修正數字，改草稿後再提交一筆新的研究更新即可。
- 還沒提交的草稿可以在畫面下方的草稿列按「↶ 復原」，或打開「草稿紀錄」回到任何一步之前，包括復原被捨棄的草稿。

## AI 改草稿時網站會怎樣？

**網站每 10 秒檢查一次草稿，AI 改過之後畫面會自動更新，並提示「某某改了草稿 N 項」，可以按「復原」撤回。**

- 你切回瀏覽器視窗時也會立刻檢查一次。
- 你正在編輯、而 AI 同時也改了草稿時，網站會把你的修改重新套到最新版本上。
- 有幾項套不上去時，網站會暫停編輯，讓你選「用最新版本並重套可以套用的修改」或「放棄我的修改」，也可以先「下載我的版本」保留下來。

## 對話摘要一定會存下來嗎？

**不一定；存摘要要靠 AI 記得呼叫，但伺服器會自動記下 AI 做過的每一個寫入動作，所以就算沒有摘要，紀錄也不會漏。**

- AI 被要求在做完重要的事、或你說要結束時，存下結論、決定和待辦。
- 你也可以直接說「把今天的結論存進研究工作台」。
- 同一個 AI 的寫入動作會自動分成一段一段，停 30 分鐘就開新的一段。
- 這些紀錄顯示在首頁的「AI」欄、公司「歷史」頁的「AI 活動」分頁、「總覽」頁和「設定」頁的「最近的 AI 活動」。
- 沒有存摘要的那一段會寫「這一段沒有存摘要（伺服器仍記下了下面每一個寫入動作）」。

## 設定頁有什麼？

**首頁右上角或側欄底部的「設定」，可以看到 AI 連線狀態、可以複製給 AI 的指示、最近的 AI 活動、Obsidian 同步狀態和備份狀態。**

- 「AI 連線」列出 Claude 桌面版、Claude Code、ChatGPT 桌面版，各自顯示「從未連線」「已連線」或「最後連線」的時間，以及最後一次寫入的時間。
- 「貼給 AI 的指示」是一段寫好的規則，按「複製」後貼到 Claude 的專案指示或 ChatGPT 的自訂指令。
- 「Obsidian」區塊顯示外掛最近一次連線、還有幾篇筆記等待寫入、哪些筆記外掛沒有更動，以及手動安裝外掛的步驟和 zip 下載按鈕。
- 「系統」區塊顯示版本和最近一次備份的時間；備份失敗時會顯示紅字。
- 進階模式下，「系統」區塊另外列出資料資料夾、資料庫檔案、資料庫版本、備份數量、安裝時間、Node.js 版本和已執行多久。
- 設定頁寫明了：這個連線機制是用來記錄每一步是誰做的，並不能防止駭客；同一台 Mac 上的程式都讀得到連線憑證。

## Obsidian 外掛怎麼裝？

**安裝程式最後會列出你的 Obsidian 筆記庫讓你選，把外掛放進去；之後在 Obsidian 裡關閉「限制模式」並啟用外掛即可。**

- Obsidian 的筆記庫（vault）就是 Obsidian 用來放筆記的那個資料夾。
- 外掛（plugin）是裝進 Obsidian 的附加程式。

1. 在安裝程式的清單輸入筆記庫的編號，外掛會被放到 `<筆記庫>/.obsidian/plugins/research-workbench-sync/`。
2. 如果 Obsidian 正在執行，請完全結束它再重新打開，新的外掛檔案才會載入。
3. 在 Obsidian 打開「設定 → 第三方外掛」（英文介面叫 Community plugins），關閉「限制模式」（Restricted mode）。
4. 在「已安裝的外掛」按重新整理，打開「Research Workbench Sync」。

要注意的事：
- 安裝時 Obsidian 沒有在執行的話，安裝程式會直接把外掛加進啟用清單，你只需要關閉「限制模式」。
- 安裝時選了 `0` 或之後想換一個筆記庫，執行安裝指令並在最後加上 `-- --obsidian`，就會重新列出清單。
- macOS 不允許終端機寫入筆記庫所在的資料夾時，安裝程式會提示你到「系統設定 → 隱私權與安全性 → 檔案與資料夾 → 終端機」打開「文件」「桌面」或「iCloud 雲碟」，再貼一次安裝指令。
- 也可以改用網站「設定」頁的「下載 Obsidian 外掛（zip）」，照那裡列的步驟手動安裝。
- 外掛的連線憑證存在外掛資料夾的 `data.json`，會跟著筆記庫同步到 iCloud 或 Obsidian Sync；請只在這台 Mac 上啟用這個外掛，也不要分享那個 zip 檔。
- 外掛只能在桌面版 Obsidian 使用。

## 外掛會在 Obsidian 寫哪些筆記？

**外掛把每家公司、每筆研究更新、每筆交易和每段 AI 對話寫成筆記，放在筆記庫的「研究工作台」資料夾裡。**

- `研究工作台/公司/`：每家公司一篇。
- `研究工作台/研究更新/<代號>/`：每筆研究更新一篇。
- `研究工作台/交易/<代號>/`：每筆交易一篇。
- `研究工作台/AI 對話/`：每段 AI 對話一篇。
- `研究工作台/_索引/`：公司總表、交易總表、AI 對話總表三篇。
- 外掛每 60 秒同步一次，可以在外掛的設定裡改成最少 30 秒；也可以從 Obsidian 的命令選單執行「立即同步」。
- 筆記建立後可以自由搬到別的資料夾，外掛靠筆記屬性裡的 `wb_id` 找到它。
- 外掛不會刪除任何檔案；你刪掉的筆記可以用「重新建立被刪除的筆記」指令找回來。

## 外掛會改到我寫的內容嗎？

**不會；外掛只改寫兩個標記之間的自動產生區，以及它自己管理的幾個筆記屬性，其他文字都不動。**

- 自動產生區的開頭是 `<!-- wb:begin … -->`，結尾是 `<!-- wb:end -->`，請不要手動修改這兩行之間的內容。
- 筆記屬性（frontmatter）是筆記最上方兩條 `---` 之間的資料；外掛只更新它自己的那幾個欄位，你加的欄位會保留。
- 每篇公司、研究更新和交易筆記都有「## 反思」段落，你寫在這裡的內容會被送回研究工作台。
- 送回的反思會顯示在網站的「交易」頁、「歷史」頁、「總覽」頁，以及交易日誌的反思欄。
- 每次修改反思都會存成新的版本，舊版本不會被覆蓋；你把反思清空時，網站會標「已在 Obsidian 清空」並顯示前一個版本。
- 正在 Obsidian 編輯器裡開著的筆記會先跳過，之後再寫入。

## 外掛說有衝突時怎麼辦？

**外掛遇到看不懂的檔案就完全不寫，網站「設定」頁的「外掛未更動的筆記」會列出這些檔案和原因，你寫的內容都沒有被改動。**

- 常見原因有：自動產生區被手動改過、標記被刪除或重複、筆記屬性沒有正確結束、檔案還沒從 iCloud 下載。
- 有兩個檔案使用同一個 `wb_id` 時（通常是 iCloud 同步衝突產生的副本），兩個都不會寫；請刪掉或合併多出來的那一個。
- 修正方法是在 Obsidian 打開那篇筆記，從命令選單執行「重建目前筆記的自動產生區」。
- 命令選單的「顯示同步衝突」也會列出這些筆記。

## 舊的交易日誌怎麼匯入？

**把舊的交易日誌筆記拖進 Claude 對話，請它「匯入研究工作台」；AI 會先列出每一筆給你確認，再寫入。**

1. 在 Claude 桌面版的 Chat 分頁開一個新對話，把 Obsidian 或其他地方的舊日誌檔案拖進去，或直接貼上文字。
2. 輸入「幫我把這份舊交易日誌匯入研究工作台」。
3. AI 會列出每一筆交易的日期、代號、買進或放空、股數、價格和出場，並逐筆預覽，這一步不會寫入。
4. 缺股數、或沒有確切日期的那幾筆，AI 會問你；台股 1 張等於 1000 股。
5. 你確認清單後，AI 才會逐筆寫入。

匯入的規則：
- AI 只會填日誌裡寫明的數字，不會自己補停損、目標價或理由。
- 每筆交易會保存日誌裡那一段原文，網站上會標「從舊日誌匯入」，並可以看到「匯入時的日誌原文」。
- 同一段原文重複匯入時，研究工作台會回傳已經存在的那一筆，不會多出一筆。
- 同一家公司已經有同一天、同方向、同股數、價格相近的交易，或這段原文匯入的交易曾經被刪除時，AI 要先問你才能寫入。
- 找不到這家公司時，AI 會先問你要不要新建。

## 資料存在哪裡、怎麼備份？

**資料只存在這台 Mac 的 `~/Library/Application Support/ResearchWorkbench/`，研究工作台每天會自動備份到同一個資料夾的 `backups/`；建議另外打開 Time Machine。**

- 每日備份在啟動時和之後每小時檢查一次，距離上一次超過 24 小時才會備份。
- 會保留最近 14 天每天一份、最近 8 週每週一份，更舊的會自動刪除。
- 升級資料庫結構前和匯入資料前，會另外各留一份永久備份。
- 自動備份和原始資料在同一顆硬碟上，硬碟壞掉或電腦遺失時會一起不見；Time Machine 是 macOS 內建的備份功能，可以把整台 Mac 備份到外接硬碟。
- 想保留單一公司的完整紀錄，在側欄底部按「匯出 JSON」下載；目前還不能把 JSON 匯入回來。
- 網站裡沒有「從備份還原」的按鈕。
- 記錄檔（伺服器的執行紀錄）放在 `~/Library/Logs/ResearchWorkbench/`。

## 怎麼更新到新版？

**在「終端機」再貼一次同一行安裝指令即可，資料會保留。**

- 安裝程式只會下載已經通過測試的版本。
- 切換前會先把資料庫另存一份；新版本 60 秒內沒有正常回應時，會自動切回上一版，並把資料庫還原成更新前的樣子。
- 已經登記好的 Claude、ChatGPT 和 Obsidian 外掛會一起更新，設定沒變的部分不會再問你。

## 出問題時怎麼診斷？

**在安裝指令最後加上 `-- --doctor` 執行，把整個畫面截圖回報。**

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/zyaoceng/organism/claude/vibrant-thompson-s3npyj/research-workbench/scripts/mac/install.sh)" -- --doctor
```

- 診斷不會修改任何東西。
- 它會逐項列出 `[ OK ]`、`[WARN]` 或 `[FAIL]`：macOS 版本、晶片、Node.js、目前版本、資料庫元件、背景服務、網址連線、備份、AI 登記狀態、Obsidian 外掛和最近的錯誤記錄。
- 想先看安裝會做什麼、但不做任何修改，在最後加上 `-- --dry-run`。
- 想看主要選項的清單，在最後加上 `-- --help`。

## 怎麼解除安裝？

**在安裝指令最後加上 `-- --uninstall`，會移除背景服務、App 和程式，但保留你的資料。**

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/zyaoceng/organism/claude/vibrant-thompson-s3npyj/research-workbench/scripts/mac/install.sh)" -- --uninstall
```

- 保留的資料在 `~/Library/Application Support/ResearchWorkbench/`，之後重新安裝會繼續使用。
- 想連資料、備份和記錄一起刪除，改用 `-- --uninstall --purge`，它會要求你打 `yes` 確認；刪除後無法復原。
- Obsidian 筆記庫裡的外掛和筆記不會被刪除；要移除外掛，請在 Obsidian 的「設定 → 第三方外掛」停用並解除安裝。

## 第一次研究一家公司要怎麼做？

**照「建立公司 → 填歷史數字 → 填預估 → 附上證據 → 提交」五步走。**

1. 首頁按「+ 新增公司」，在最上面的搜尋框輸入代號或公司名稱（例如 `7899` 或「景美」），點搜尋結果，公司名、代號、交易所、資料來源代號和股價來源會自動填好。
2. 網站用標準研究範本建立一棵樹：EPS 底下有營收、毛利率、費用、業外、稅、淨利、稀釋股數；本益比底下有 EPS 成長、ROIC、再投資報酬率；最下面是目標價；期間預設是前兩年為實際（A），今年和後兩年為預估（E）。
3. 把範本裡的三個業務節點改成你自己的業務切法：點一列，按 `F2` 改名，按 `A` 新增子項目。
4. 在實際年度（A）的格子填財報數字，在預估年度（E）填成長率、毛利率等假設；點格子直接打數字，按 Enter 換下一列，百分比格打 `40` 就是 40%。
5. 選一個重要假設，在右邊面板加上證據：貼網址按 Enter、`Ctrl+V` 貼截圖，或寫一則筆記。
6. 按畫面下方的「檢查並提交」，確認自動填好的標題，寫上知情日期（你知道這些資訊的日期）和理由，按「提交研究更新」。

## 單位要怎麼設？台股和美股有什麼不同？

**建立公司時選的貨幣決定範本的預設單位：新台幣用「億元、億股」，美元用「百萬美元、百萬股」。**

| | 台股例子：光寶 2301 | 美股例子：Vertiv VRT |
|---|---|---|
| 建立公司時的交易所 | TWSE（上櫃選 TPEx） | NYSE 或 NASDAQ |
| 自動帶出的代號 | 2301.TW（上櫃為 .TWO） | VRT |
| 貨幣 | TWD | USD |
| 營收、毛利、淨利的單位 | TWD 億 | USD mn（百萬美元） |
| 稀釋股數的單位 | 億 sh（億股） | mn sh（百萬股） |
| EPS 的單位 | TWD/sh（每股新台幣） | USD/sh（每股美元） |

- EPS 等於淨利除以稀釋股數，所以淨利和股數必須用同一個單位；兩邊不一致時，EPS 這一列會出現警告，並寫出結果差了幾倍。
- 單一節點的單位在右邊面板上方的「設定」裡改，基本模式要先點開「設定」。
- 美元和新台幣的數字不能直接相加，請先建一個匯率節點把美元換成新台幣；直接相加會出現「幣別不同」警告。
- 同一種貨幣但位數不同（例如億元加百萬元）時，會出現「數量級不同」警告。

## 公式要怎麼寫？

**在右邊面板的公式欄用中括號寫節點名稱，按 `Ctrl+Enter` 套用。**

- 例子：`[TAM] * [市占率] * [ASP]`。
- 去年乘成長率：`PREV([營收]) * (1 + [成長率])`，`PREV` 讀前一期。
- 加總底下所有子業務：`SUM(CHILDREN())`，之後新增的業務會自動算進去。
- 指定某一年：`[EPS]@FY2028`。
- 公式形成循環時會被擋下，並顯示循環路徑。
- 輸入值空白時，下游格子會顯示「—」，系統不會把空白當成 0。
- 藍字是你手打的數字，黑字是公式算出來的；灰底欄位是實際年度，白底是預估年度。

## 空頭、基準、多頭三種情境怎麼設？

**基準情境放共用數字，空頭和多頭只記跟基準不同的格子。**

- 畫面左上角切換情境，或在樹上按數字鍵 1、2、3。
- 在空頭情境下改格子，只會記成空頭的覆寫，基準數字不變。
- 實際年度三種情境共用，不能覆寫。

## 收到新資訊時要怎麼更新？

**先附證據，再改所有相關假設，最後一次提交成一筆研究更新。**

- 改完先打開底部面板，會看到改了哪些格子，以及 EPS、目標倍數和目標價在三種情境下怎麼變。
- 基本模式提交時，會自動引用這次新連結的證據；想自己勾選要引用哪些證據，在進階模式提交。
- 看完新資訊決定不改任何數字時，照樣可以提交，這筆會記成「檢查點」，代表你看過並維持原判斷。
- 知情日期不能比上一筆早，也不能引用在知情日期之後才發表的資料，這樣紀錄裡不會混進當時還不知道的資訊。
- 改錯了可以按 `Ctrl+Z` 復原；還沒提交的草稿可以整份捨棄。

## 目標本益比要怎麼決定？

**在「估值」頁自己輸入三種情境的本益比，系統只負責整理判斷用的資料。**

- 歷史本益比區間和同業表要自己填，歷史區間和每一家同業都可以寫來源和日期。
- 每種情境的本益比旁邊要寫理由，這些理由會跟著研究更新一起存檔。
- 填上三種情境的機率，系統會算出機率加權目標價，首頁進階模式的「加權目標價」欄就是這個數字。

## 幾個月後怎麼回頭檢討？

**打開「歷史」頁，所有研究更新都在時間軸上，每一筆都能完整還原。**

- 點任一筆更新，會看到當時的理由、引用的證據、改了什麼、對 EPS 和目標價的影響、當時的股價和提交者。
- 按「查看快照」可以用唯讀模式看當時的整棵樹。
- 按「還原到草稿」會把舊版本放回草稿，提交後成為新的一筆，舊紀錄不會被改寫。
- 「預估演變與校準」分頁列出同一個數字在每次更新時的估計值；標記錯誤的研究更新不會列入。
- 「檢討」分頁可以寫檢討，勾選錯誤出在證據品質、證據解讀、假設幅度、財務模型／公式、時點／催化劑、估值倍數、交易執行或風險管理。

## 交易紀錄要怎麼用？

**在「交易」頁記錄進場，系統自動帶入當天的 ATR、2 倍 ATR 停損和當時的目標價。**

- ATR（平均真實區間）是股價每天平均的波動幅度，用來設定停損距離。
- 「交易」頁最上面是 K 線圖，標出進出場點、停損線、催化劑和三種情境的目標價線。
- 基本模式的 K 線圖固定顯示一年、20 日和 50 日均線、14 日 ATR。
- 目標價取自進場日當天已經提交的研究更新。
- 出場後填出場日期、價格和理由；表格會算報酬和 R 倍數。
- 每筆交易下方會顯示 Obsidian 筆記裡的反思。

## 股價抓不到怎麼辦？

**到「交易」頁右邊按「🔍 用代號或名稱搜尋」，點正確的那一筆，網站會自動換成對的代號和股價來源。**

- 最常見的原因是代號後綴選錯：上市股票在 Yahoo 是 `.TW`，上櫃和興櫃股票是 `.TWO`。
- 台股建議用 FinMind 當股價來源，它有上市、上櫃、興櫃的每日股價，不用註冊就能用，每小時有請求次數上限。
- 美股用 Yahoo，搜尋英文名稱或代號即可，例如 `NVIDIA` 或 `NVDA`。
- 全部來源都抓不到時，可以從別處下載日線 CSV，在進階模式的同一頁匯入。

## 常用快捷鍵有哪些？

**改結構和切情境的按鍵要先在樹狀圖上點選一列才有作用；`Ctrl+Z` 在公司頁面任何地方都能用，`Ctrl+K` 在首頁、交易日誌和公司頁面都能用。**

| 按鍵 | 作用 |
|---|---|
| `A` | 新增子項目 |
| `S` | 新增同層項目 |
| `F2` | 改名 |
| `Tab` / `Shift+Tab` | 往內縮／往外移一層 |
| `Alt+↑` / `Alt+↓` | 上移／下移 |
| `Ctrl+D` | 複製整個分支 |
| `Delete` | 刪除（可用 `Ctrl+Z` 復原） |
| `1` `2` `3` | 切換空頭／基準／多頭 |
| `Ctrl+Z` | 復原 |
| `Ctrl+K` | 搜尋或切換公司 |
| `Ctrl+V` | 把截圖貼成證據，連到目前選取的節點 |

## 目前有哪些限制？

**AI 只能從這台 Mac 上的桌面版 App 連到研究工作台，而且 Mac 要開著、醒著。**

- claude.ai 網頁版、Claude 手機 App、ChatGPT 網頁版和 ChatGPT 手機 App 都連不到研究工作台。
- Claude 桌面版的 Cowork 看不到這個連接，請用 Chat 分頁。
- ChatGPT 桌面版只在 Work 模式、不在專案裡的對話可用。
- Mac 睡眠或關機時，AI 用不到研究工作台，Obsidian 外掛也無法同步。
- 資料只存在這台 Mac 上，自動備份也在同一顆硬碟，請打開 Time Machine。
- 研究更新提交後不能修改或刪除，只能標記錯誤。
- 網站裡沒有「檢查更新」和「從備份還原」的按鈕；更新請重跑安裝指令。
- 只能匯出 JSON，還不能匯入 JSON。
- 一個模型只能用一種期間頻率，年度或季度擇一。
- Yahoo 股價用的是非官方介面，隨時可能變動。
- Mac 版目前沒有設定 FinMind 權杖或富果 API 金鑰的地方，所以 FinMind 會用免註冊的請求上限，股價來源選單也不會出現富果。
